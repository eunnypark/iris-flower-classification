# 붓꽃 품종 분류 (Iris Flower Classification)

## 1. 프로젝트 소개

머신러닝을 활용하여 붓꽃의 품종을 분류하는 입문 프로젝트입니다.

Scikit-learn에서 제공하는 Iris 데이터셋을 사용하여 데이터 탐색부터 모델 학습, 예측 및 성능 평가까지 머신러닝의 기본적인 과정을 실습했습니다.

## 2. 데이터셋

- **데이터셋:** Iris Dataset
- **출처:** Scikit-learn (`sklearn.datasets.load_iris`)
- **데이터 개수:** 150개
- **입력 특성:** 4개
- **분류 대상:** 3개 품종

### 입력 특성

- 꽃받침 길이 (Sepal Length)
- 꽃받침 너비 (Sepal Width)
- 꽃잎 길이 (Petal Length)
- 꽃잎 너비 (Petal Width)

### 분류 대상

- Setosa
- Versicolor
- Virginica

## 3. 사용 기술

- Python
- Google Colab
- Scikit-learn
- NumPy
- Matplotlib

## 4. 사용한 머신러닝 모델

세 가지 분류 모델을 학습하고 성능을 비교했습니다.

1. 로지스틱 회귀 (Logistic Regression)
2. 결정 트리 (Decision Tree)
3. 랜덤 포레스트 (Random Forest)

데이터셋은 학습 데이터 80%, 테스트 데이터 20%로 분리했습니다.

## 5. 실험 결과

| 모델 | 정확도 |
|---|---:|
| 로지스틱 회귀 | 96.7% |
| 결정 트리 | 93.3% |
| 랜덤 포레스트 | 90.0% |

이번 실험에서는 로지스틱 회귀 모델이 가장 높은 정확도를 기록했습니다.

※ 위 결과는 한 번의 학습용·테스트용 데이터 분할을 통해 얻은 결과이며, 모델의 일반적인 성능을 의미하지는 않습니다.

## 6. 학습 내용

이번 프로젝트를 통해 다음 내용을 학습했습니다.

- Scikit-learn을 이용한 데이터셋 불러오기 및 탐색
- Matplotlib을 이용한 데이터 시각화
- 학습 데이터와 테스트 데이터의 차이
- `fit()`을 이용한 모델 학습
- `predict()`를 이용한 예측
- 로지스틱 회귀, 결정 트리, 랜덤 포레스트의 기본 원리
- 정확도(Accuracy)를 이용한 분류 모델 평가

## 7. 향후 개선 방향

- 교차 검증(Cross Validation)을 통한 모델 성능 평가
- 모델 하이퍼파라미터 변경 및 성능 비교
- 다양한 데이터셋을 활용한 분류 문제 실습
